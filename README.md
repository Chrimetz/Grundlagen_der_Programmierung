# Grundlagen der Programmierung

Dieses Repository enthält die Lösungen zu den Übungsblättern aus der Vorlesung **Grundlagen der Programmierung** an der Hochschule Osnabrück im Institut für Duale Studiengänge.

Die Aufgaben und Beispielanwendungen sind in Java umgesetzt.

## Struktur

- `Uebungsblatt_01` – Berechnung der Fahrtkosten
- `Uebungsblatt_02` – Ticketpreise und Dreieckprüfung
- `Uebungsblatt_03` – Zahlenraten und Analyse von Ziffern
- `Uebungsblatt_04` – Notenberechnung und Kalendereigenschaften

## Voraussetzungen

- Java Development Kit (JDK)
- Eine Java-IDE wie IntelliJ IDEA oder ein Terminal

## Programm starten

Wechsle im Projekt ins Verzeichnis `src` und kompiliere anschließend die gewünschte Klasse. Beispiel:

```powershell
javac Uebungsblatt_03\GuessNumbers.java
java Uebungsblatt_03.GuessNumbers
```

Die einzelnen Programme können auch direkt über IntelliJ IDEA gestartet werden.
